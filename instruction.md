# Debug a Failing Microservice

You are given a Python microservice that fails to start correctly.

Your goal is to make the application run successfully.

## Requirements:
- The application should start without errors.
- The root endpoint ("/") should return "App is running".
- All dependency issues must be resolved.
- The service should correctly connect to Redis.

## Notes:
- The application is located in `/app/`.
- You may modify any files in `/app/`.
- Do not hardcode outputs; fix the root cause of the issues.
